# Programming Language Icons

A unified flat-style icon pack for programming languages and GitHub Linguist-recognized languages/formats.

## Production rules

- Every icon must be generated with **Image**.
- Do not substitute SVG, Pillow, canvas, or other programmatic drawing for image generation.
- Generated source images must be preserved byte-for-byte when uploaded; no redrawing, recompression, or silent replacement.
- Organization, naming, indexes, previews, and checksums may be generated separately without modifying the icon files.

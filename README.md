# Programming Language Icons

A unified flat-style icon pack for programming languages and GitHub Linguist-recognized languages/formats.

## Current contents

- `icons/` — 1024×1024 transparent PNG icons
- `batches/batch-001/` — first delivery batch, including preview and indexes

## Batch 001

Python, JavaScript, TypeScript, Java, C, C++, C#, Go, Rust, and Swift.

> These are original redesign concepts rather than copies of the official logos.
